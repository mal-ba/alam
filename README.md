# alam — 내 계획표 + 알림

구글 계정으로 로그인해서 쓰는 계획표 앱과, 그 계획대로 휴대폰에 알림을 보내 주는 자동 실행이에요.

- 앱: **https://mal-ba.github.io/alam/** (홈 화면에 추가하면 앱처럼 써요)
- 데이터: **Supabase** 에 저장, **로그인한 구글 계정마다 자기 것만** 보여요 (행 단위 보안)
- 알림: **ntfy** 앱 (무료) 으로 와요
- 처음 설정: [SUPABASE_SETUP.md](SUPABASE_SETUP.md)

> 🔒 이 저장소는 공개예요. 앱 **코드**만 있고, 개인 일정·보고서·시험·시간표는 저장소가 아니라 Supabase 에 있어요.
> 지도에 저장한 장소도 Supabase 내 계정에 저장돼요 (`places.json`). 예전에 기기에만 저장했던 장소는 지도를 처음 열 때 계정으로 옮겨져요.

## 알림 (GitHub Actions → `run_supabase.py`)

- **매일 22:00 (한국)**: 다음 날 알람을 미리 예약 — GitHub 실행이 몇 시간 늦어져도 제시간에 와요
- **매일 00:00**: 어젯밤 쓴 보고서의 외울 것·기억할 것 "🧠 어제 보고서 복습", 밤 예약이 실패했으면 그날 알람 대신 예약
- ⚙️ 에 ntfy 토픽을 넣은 **계정마다** 그 계정 일정으로만 예약, 하루 한 번만 (중복 없음)
- 공개 로그에는 이메일·일정 내용 없이 개수만 남아요

기본 알림 구성 (⚙️ 기본 시간표의 `todo_reminders`, `report_reminder` 로 바꿀 수 있어요)

|---|---|
| 00:00 | 오늘 일정 요약 (할 일, 시간표, 다가오는 시험 D-day) |
| 07:30 · 08:00(+등교 시간) | ☑️ 오늘 해야 할 일 |
| 요일별 오후 | ☑️ 할 일 |
| 21:00 | ☑️ 할 일 + ⏰ 남은 일정 |

| 일요일 0시 · 매월 1·2일 0시 | 주간 계획표(GRIT·MUST DO) · 월간 계획표(목표) |

## 기본 시간표 형식 (⚙️ → 기본 시간표)

[`docs/schedule.example.json`](docs/schedule.example.json) 참고.

- `weekly`: 요일별 반복 일정 (0=월 … 6=일), `remind_before` 몇 분 전 알림 (`[]`=없음, `[0]`=정각)
- `school`: 교시 시간표(`timetable`, `period_times`), 격주 과목(`alternating`), 쉬는 날(`off_days`), 시험날(`exam_days` — 등교만 남김), 방학(`vacations`), 학사 메모(`notes`)
- 날짜별로 바꾸는 건 앱의 주간/월간 표에서 (우선순위: 주간 표 > 월간 표 > 기본 시간표)

## 파일

| 파일 | 내용 |
|---|---|
| `docs/` | 앱 (GitHub Pages) |
| `docs/config.js` | Supabase 주소·publishable 키 (공개돼도 되는 값) |
| `supabase/schema.sql` | 데이터 테이블 + 행 단위 보안 |
| `news.py` | 구글 뉴스 RSS → `docs/news.json` + 연도별 보관함 `docs/news/<분야>/<연도>.json` (`.github/workflows/news.yml`, 매시간 깨워서 3시간 지났으면 모음) |
| `news_archive.py` | 2000년~지난달 기사를 분야·달마다 조금씩 채움, 진행 상황 `docs/news/progress.json` (`.github/workflows/news-archive.yml`, 4시간마다 / Actions 에서 바로 실행) |
| `docs/learn.json` | 코딩 공부 강의 내용 (`learn_gen.py` 로 만들어요: `python learn_gen.py docs/learn.json`) |
| `alarm.py` | 계획표 계산·알림 예약 로직 |
| `run_supabase.py` | 계정별로 `alarm.py` 실행 (Secrets: `SUPABASE_URL`, `SUPABASE_SERVICE_KEY`) |
| `.github/workflows/midnight-alarm.yml` | 매일 22:00 · 00:00 자동 실행 |
